Current 2026-07-06 comparison convention: do not put `replay_command` metrics in
the primary quality comparison table. For each future motion row, compare only

the policy input, while computing metrics against the original `motion.npz` via
`--metrics-reference-motion`; it answers whether the optimized motion is a good
bare-policy reference, not whether replayed window commands match MJX.
