## RTX 4090 Bring-Up Checklist

1. Checkout `codex/g1-wbc-mjx-full-rollout` on the RTX 4090 machine.
2. Confirm dependency and CUDA/JAX visibility:

   ```bash
   CUDA_VISIBLE_DEVICES=0 PYTHONPATH=. ./.venv/bin/python - <<'PY'
   import jax
   print(jax.devices())
   PY
   ```

3. Run the targeted unit tests before GPU experiments:

   ```bash
   PYTHONPATH=. ./.venv/bin/python -m unittest \
     tests.tasks.g1_wbc.test_mjx_rollout \
     tests.tasks.g1_wbc.test_mjx_backend_integration \
     tests.tasks.g1_wbc.test_mjx_components
   ```

4. Run a short MJX guided diagnostic on the RTX 4090 and inspect nested `mpc`
   fields for runtime GPU name, visible devices, accepted windows, warmup time,
   and steady-state time.
5. Run formal sharded acceptance rows, one motion inference per GPU process.
   For a single RTX 4090, use only `CUDA_VISIBLE_DEVICES=0`.
6. Generate the final acceptance report only after all six MJX row sidecars
   exist.

## Formal Acceptance Command Template

```bash
CUDA_VISIBLE_DEVICES=0 PYTHONPATH=. ./.venv/bin/python -u \
  scripts/run_g1_wbc_mjx_acceptance.py \
  --baseline-manifest /data_team/junsong/model-based/g1_wbc_mjx_runs/stage0_baseline_legacy_20260704_h100_gpu0/baseline_manifest.json \
  --output-dir /data_team/junsong/model-based/g1_wbc_mjx_runs/mjx_acceptance_guided_4090 \
  --device cuda:0 \
  --reuse-existing-ok \
  --skip-report \
  --only-motion jump \
  --only-seed 0 \
  --mjx-guided-candidate
```

After all six rows are present, rerun without `--skip-report`, `--only-motion`,
or `--only-seed` to produce the acceptance report.
